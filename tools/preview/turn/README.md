# めくりの試写室 (#43 / #42)

本物のめくりの演出(v0.32)と同じ `extension/src/content/turnfx.js` で描く。

リポジトリの一番上で:

```sh
python3 -m http.server 8000
```

http://localhost:8000/tools/preview/turn/ を開く。いつもの試写室にもリンクがある。
ES modules を使うので、HTML をファイルとして直接開かず HTTP で見る。

## 比較できるもの

- **余白に広げる(A・本物の既定):** 本文の紙面と周囲16pxを常に除外。水彩と粒が外に広がる。
- **短い全画面(B・本物では「画面いっぱいに広げる」):** 紙面の内側も使って輪・渦・光と粒が広がる。本文上は最長360ms。本文の表示後に検知した場合はAに切り替える。
- ふだんの型(雰囲気が分からないとき・本物はいまこれだけ)と雰囲気7種、粒10種、大きさ3段、勢い、θ、明暗背景、動きを減らす設定。
- コマ止め: 0〜1800msを手で動かす。通常再生は「めくる」か Space / →。

最初は「しんみり / 雨粒 / 大 / θ=8」。Aでめくり、1秒以上空けてBでもめくる。
粒の配置は同じ乱数の種なので比較できる。「本文の表示後」にするとBも本文に重ならない。
「7つの場面を順に見る」で7種類を2.1秒間隔で再生できる。停止・手動操作・非表示・ページ離脱で止まる。
雰囲気を変更すると試写用の短い話が替わり、色もすぐ切り替わる。「前の場面から色をなじませる」を選べば次のめくりから徐々に寄せる比較もできる。
自動判定や、実際に読んでいる本の内容は使わない。

| 雰囲気 | 構図と動き |
|---|---|
| ふだん | いつもの水彩の3色の輪がふわっと広がる(あたたかいと同じ動きで、色だけ違う) |
| 穏やか | 大きな葉と横風の曲線がゆったり通り抜ける |
| あたたかい | 輪がふわっと広がり、粒も円を描く |
| しんみり | 長い雨筋が斜めに流れ落ちる |
| 緊迫 | 鋭い斜線と細長い粒が素早く横切る |
| 不思議な気配 | 螺旋と光が渦を巻く |
| うれしい | 花びらと曲線が扇状に跳ねる |
| 驚き・発見 | 光の柱と羽根が下から昇る |

同じ色・粒を指定しても7種類の軌道とアルファの模様は異なる。Aは紙面の外側、Bは紙面の内側からも始まる構図。

## 再現用URL

- `?mode=edge&mood=plain&at=180` / `?mode=full&mood=plain&at=180` (ふだんの型)
- `?mode=edge&mood=calm&motif=forest&size=large`
- `?mode=full&mood=sad&motif=rain&theme=dark&at=180`
- `?mode=full&timing=late&at=180` (遅い検知)
- `?mode=full&at=360` (本文上はすでに透明)
- `?mode=full&at=800` (粒は消え、余白の残光だけ)
- `?theta=0&at=180` / `?reduced=1&at=180`

`at` を付けるとコマ止め。`energy=0|1|2`、`theta=0..8`、`blend=1` も指定できる。

## 実装と検証

`extension/src/content/turnfx.js` は型・タイミング・描画。純粋な `planTurn`・`particleAt`・`frameAt` をNodeでも検証する(`tests/extension/turnfx.test.mjs`)。
`preview.js` は比較画面と試写用の本文。通信・保存・計測をしない。
粒の画像はCanvasで一度だけ焼き、キャッシュを96件までに制限する。
粒は720msで消える。以降はCanvasを再描画せず、余白の残光だけを合成側で1800msまでに消す。
1秒以内のめくりは演出を重ねず、待ち行列も作らない。ページ自体は進む。
OSのreduced-motionは画面のチェックより優先し、余白の静止色だけにする。
非表示・リサイズ・スクロール・設定変更では古い描画を消し、ページを離れたら後片付けする(本物はスクロールでは消さず、本文の枠が描かない枠からはみ出したまま0.4秒落ち着いたら消す)。

```sh
node --test 'tests/extension/*.test.mjs'
```

Chromiumでも、本文上のアルファを23条件(2案×明暗×5時刻、および遅い検知・動きを減らす・θ=0)で確認。
7種類の雰囲気、連打、待ち行列がないこと、OSのreduced-motion、390px幅の配置も確認済み。
ブラウザのJavaScriptエラーは0件。
さらに7場面×2案の本文上が360msで透明になること、色と粒をそろえても7種類のアルファ模様が異なること、場面の順次再生と停止を確認。

**本物への接続(v0.32):** めくりの光の代わりに、ふだんの型で出る。置き場所はダッシュボードの「めくり」で本人が選ぶ(既定はA)。
雰囲気の自動判定(#42 の `/mood`)と本物のPlay ブックスでの評価は次の段階。仕組みは docs/design.md §6 の Micro。
