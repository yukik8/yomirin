# 場面の絵の試写室 (#50 → #34)

Claude が書いた形のデータに、端末の決まった画風を掛けて、余白に置く一枚の絵にする。

- 形のデータ: SVG の path と、色の名前
- 画風: 色鉛筆・水彩・紙

めくるたびに 下描き → 淡い色 → 色が濃くなる と進んで、そこで待つ。章の終わりで仕上がる(#34 の見た目)。
判定基準と結果は #50 に書く。

## 見る

リポジトリの一番上で:

```sh
python3 -m http.server 8000
```

http://localhost:8000/tools/preview/scene/ を開く。いつもの試写室にもリンクがある。
ES modules を使うので、HTML をファイルとして直接開かず HTTP で見る。

- **1枚ずつ:** 本文のページの右下の余白に絵が出る。比べられるもの:
  - 場面・版(見本・モデル・回)・段
  - 画風の有無(外すと Claude が書いたままの形)
  - 大きさ・暗い背景
  - 描いた物と、本文の根拠の語句(○ は本文にそのまま有る)
  - 時間・トークン・費用・描画の時間
- **全部を並べる:** `?view=grid`。場面ごとに、版を行に、段を列に並べる。いちばん右は画風なし。人物を描かない・画風がそろう・場面が分かる・段階の4つは、ここを見て本人が決める

再現用URL:

- `?scene=ginga&stage=4&theme=dark`(夜の場面の仕上がり・暗い背景)
- `?scene=lemon&stage=1`(下描き)
- `?scene=torokko&stage=4&styled=0`(画風なし)
- `?view=grid&styled=0`(全部を画風なしで)

## 作る(費用がかかる)

```sh
server/.venv/bin/python tools/preview/scene/generate.py                                  # Opus 5.5 で3場面 × 3回
server/.venv/bin/python tools/preview/scene/generate.py --model claude-sonnet-5-5 --runs 1
server/.venv/bin/python tools/preview/scene/generate.py --model claude-haiku-5-5 --runs 1
```

- API キーは環境変数 `ANTHROPIC_API_KEY`(無ければ `server/.env` の同じ名前)
- `samples/<場面>.<モデル>.<回>.json` に書き、`samples/index.json` を書き直す。もうあるファイルは作り直さない(消すと作り直す)
- 渡すのは本文だけで、書名と作者は渡さない(#34 で拡張が送るのも、読み終えた段落だけ)
- 呼び方は構造化出力(json_schema)・ストリーミング・effort は medium(`--effort` で替えられる)
- Opus・Sonnet ではサーバ側のフォールバックを付ける(server/main.py と同じ)。替わったときは `served_model` に残り、費用もそのモデルで出す
- 構造化出力は、新しい schema の最初の1回だけ準備の時間がかかる(24時間はキャッシュされる)。1回目の時間が長いときは、そのことを結果に書く

## 集計

```sh
node tools/preview/scene/check.mjs
```

Markdown の表を出す(#50 の「結果」に貼る)。

- 1枚ずつの行: 検査・根拠・形の数・時間・トークン・費用
- モデルごとの行: 判定基準(形が通る・本文に根拠・時間・費用)と比べて ✓ / ✗

`--schema` は Claude に渡す JSON Schema、`--index` は `samples/index.json` を書き直す。

## 仕組み

- **`scene.js`**(純粋な関数。`tests/extension/scene.test.mjs`)。見込みが立てば `extension/src/content/scene.js` に移す
  - `sceneSchema`: Claude に渡す schema
  - `checkScene`: 形のデータを検める
  - `grounded`: 根拠の語句を数える
  - `buildSvg`: 段ごとの SVG を組み立てる
  - `paint`・`frame`: 層の形を画風で描き、紙に載せる。`buildSvg` も章の絵巻(`../emaki/`・#51)もこれを使う
- **形のデータ:**
  - `ground`(奥の大きな面)
  - `forms`(物の面。奥から手前の順)
  - `lines`(色鉛筆の線)
  - `light`(光るものそのものの形)
  - `items`(描いた物と本文の根拠の語句。試写室で見るだけで、絵には入れない)
  - 形は path の `d` だけ(viewBox 320×240)。色は `COLORS` の名前、濃さは `TONES`、太さは `WIDTHS`
- **検査:** 次のものは、形ごと落として数える。層が無いときや、描くものが無いときは絵にしない
  - path の文字(コマンドと数字)以外
  - 表に無い名前
  - 座標の絶対値が 1000 を超えるもの
  - 数と長さの上限(`LIMITS`)を超えたもの
- **安全:** SVG に入るのは、検査を通った `d` と、端末の表の色の値だけ。表示は `<img src="data:image/svg+xml,…">` なので、スクリプトも外部の読み込みも動かない
- **段:**

| 段 | 見せるもの |
|---|---|
| 1 下描き | 線だけ(鉛筆の色) |
| 2 淡い色 | 地と物を薄く |
| 3 色が濃くなる | 地と物を濃くし、線に色を付ける |
| 4 仕上がり | 光を足す |

- **画風:** 値はすべて `scene.js` の `DEFS`
  - 水彩: 縁を揺らす(`feDisplacementMap`)→ 細かい粒と大きなむらで顔料のむら → 縁に色が溜まる。物は multiply で重ね、地は普通に重ねる
  - 物の下には、同じ揺れで紙の色を敷く(前の物から奥が透けないように)
  - 色鉛筆: ゆるい揺れと紙の目のかすれ、少しずらした二度描き
  - 紙: 生成りの地に茶のノイズ。絵の縁は、揺れながらぼけて紙に溶ける
  - 光: 遠くまでぼけた光と近くの光の上に、芯を残す(screen)
- **重さ:** 600×450px に描き切るまで、1枚 20〜50ms(ヘッドレスの Chrome・CPU で描く・見本の3枚)。めくった瞬間に1回だけ描く

## 見本を描いて分かったこと

`samples/*.sample.json` は、Claude Code が同じ指示で手で書いた3枚。道具を確かめるためのもので、計測していないので判定には使わない。

- 下描きの段に映るのは `lines` だけ。主な物の輪郭を線でも描かせないと、下描きがスカスカになる(指示に入れた)
- 光の輪まで形で描くと、光る物が平たい円に潰れる。そこで、光る物そのものの形を描かせ、輪は端末で付ける(指示に入れた)
- 水彩を重ねるだけだと、手前の物から奥が透けて前後が読めない。物の下に紙を敷いて直した
- 濃い色の広い面(夜空)は、むらを強くすると汚れたまだらに見える。むらは控えめにした
- 地まで multiply で重ねると、暗い地の上の明るい地(夜空に描いた天の川の帯)が消える。multiply は物だけにした(Claude の版を見て分かった)
