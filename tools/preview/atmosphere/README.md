# ページの余韻の試写室 (#52)

めくった瞬間に、直前に読み終えたページの空気をSVGで画面へ広げるローカル試作。

リポジトリのルートで `python3 -m http.server 8931 --bind 127.0.0.1` を起動し、[試写室](http://127.0.0.1:8931/tools/preview/atmosphere/) を開く。サーバが起動済みならそのまま開ける。

- 『トロッコ』を12ページで読む。「読み終えて、めくる」または Space / →。← で戻る。
- 最初に開いたページでは演出を出さない。めくって読み終えたページの演出だけを出す。
- 試写の設定: 本文に連動 / 毎回同じ / なし、強さ0〜150%、ページ移動、動きを減らす。
- 「余韻をもう一度」で直前の演出を再生。「いまの余韻を確かめる」で根拠とコマ止めを見る。未読の根拠は表示しない。
- `?page=6` は6ページから開始（そのページを読み終えてめくると広がる演出）。`?mode=off` / `?mode=constant` は比較用。

本文は既存 `emaki/books.json` の公開作品を使用。`score.js` の台本は手付けで、各ページに存在する語句を照合する。AI自動分類の精度を評価するものではない。外部API通信・課金・保存はない。

## 演出

`fx.js`: 色面、曲線、粒、細線をSVGで描く。具体的な物・人物は描かない。風・薄明かり・疾走・広がり・落ち着かなさ・灯り・解放・余韻を、軌道と密度で描き分ける。

本文全体と周囲12pxをマスクした層と、本文上にもかかる弱い色の層を分ける。本文上は360msで透明、全体は1600msで透明になりDOMを破棄する。読書中に動き続けない。連打で重ねず、戻る・ページ指定・設定変更・リサイズ・非表示で消す。OSまたはチェックのreduced-motionでは余白の色のフェードのみ。コマ止めは試写用に消去を止め、スクロール時に除外領域を取り直す。
