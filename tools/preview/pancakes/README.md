# パンケーキの小さな劇場

Refs #54。元の6枚のパンケーキの絵を、そのまま主役にした試写室。SVGは画像の配置と短いしぐさのためだけに使う。

リポジトリ直下で `python3 -m http.server 8931` を起動し、`http://127.0.0.1:8931/tools/preview/pancakes/` を開く。起動済みなら既存サーバを使う。

## 絵としぐさ

- `extension/assets/story/pancakes-1.webp`〜`6.webp` を直接読み込む。画像ファイル・色・質感・輪郭の加工、再生成なし。
- 原寸比率と共通倍率、足元の位置をそろえて表示する。クマと食べ物の接触を保ち、手足の部品分割はしない。
- 最初の5枚に小さな傾き・踏ん張り・落ち着きを添えた12段階の台本。12枚の新しい絵ではない。同じ原画の繰り返しが含まれるため、長時間の飽きは引き続き評価が必要。
- 動きは900〜1120ms。傾きは最大3度。終わると等倍変形なしの原画へ戻る。原画切り替えは180msの画像のみのクロスフェード。全画面フラッシュ・常時ループなし。
- 高い山（5枚目）まで進んだ章末のみ6枚目へ。早い章末はその時点の原画で静かに終わる。絵の枚数や量を生成・補間しない。

## 試し方

- 「動きを見る」: 一操作で一場面。「いまのしぐさをもう一度」で再生。
- 「試写の設定」: コマ選択、原画のまま見る（動きなし）の比較。
- 「本文の横で読む」: 公開本文「トロッコ」を通常9ページ／細かい区切り60ページで読む。長編そのものではなく、長い章の進行を模擬する。
- 読書モードは不規則な間隔で進む。280ms以内の二重入力を無視し、1200ms以内の連続操作では新たな動きを抑制する。
- OSのreduced-motionにも対応。非表示タブでは動きを取り消して最終静止状態へ。
- 本文を演出に渡さない。保存・外部API通信なし。本番のθや章境界への接続はまだない。

## 検証

`node --test tools/preview/pancakes/story.test.mjs`。長い章の待ちと順序、重複通知、途中終了、終幕を先に見せない条件を確認する。

`story.js`: 台本と進行。`scene.js`: 元絵を載せるSVGと有限の動き。`preview.js`: 試写操作と本文。公開本文とページ分割は `../emaki/` を利用する。
