# パンケーキの小さな劇場 — あと、ちょっと。

Refs #54。くまが頂上のブルーベリーを欲しがる、因果のつながった短い無言劇。SVGは完成した絵を表示・切り替え・短く動かす裏方。

リポジトリ直下で `python3 -m http.server 8931` を起動し、`http://127.0.0.1:8931/tools/preview/pancakes/` を開く。起動済みなら既存サーバを使う。

## 物語と連続性

| 場面 | クマの行動 | ブルーベリー | 山・他の果物 |
|---|---|---|---|
| 1 | 頂上を見上げる | 頂上 | パンケーキ4枚、いちご1個、ラズベリー1個 |
| 2 | 背伸びするが届かない | 頂上 | 同じものが残る |
| 3 | しがみついて登る | 頂上 | 同じものが残る |
| 4 | 体重で傾く山を支える | 右端へ転がる | 4枚のまま傾く。果物は上に残る |
| 5 | 山を押し戻しながら実を受け止める | 手の中 | 4枚の山が残る |
| 6 | 山の隣で満足する | 手の中 | 山と残りの果物がそのまま残る |

全場面を通してブルーベリーは1個、バターは0個。章末に山を小さい別の絵へ差し替えない。元の6枚には飾りと枚数の不連続があるため、今回は元絵を参照して一続きのシートを新たに生成した。元画像は変更していない。

## 試し方・実装

- 「動きを見る」: 最初の4場面を順に進め、「結末を見る」で受け止める→ほっとする、の2場面を再生。
- 「本文の横で読む」: トロッコを通常9ページ／細かい区切り60ページで読む。動機→試行→危機までを章内に分散し、解決は章末。途中の章末は現在の場面で終わり、解決を先取りしない。
- 「いまのしぐさをもう一度」: 終幕では受け止めるところから再生する。
- 設定の「動きを止めて見る」またはOSのreduced-motionでは最終静止状態へ。280ms以内の二重入力は無視し、1200ms以内の連打では動きを抑制。
- 通常は1000ms、章末は650msで受け止める絵から満足する絵へ切り替え、合計1150msで静止する。読む間は動かない。
- 本文を演出に渡さない。保存・外部API通信なし。本番のθや実際の章境界への接続なし。

`story.js` が状態と小物の台帳、`scene.js` がシートのセル表示と動き、`preview.js` が試写操作。シートは3列×2行、1536×1024px、1セル512px。SVGの入れ子viewportでセルを選択し、画像自体は切り分け・色変更しない。

## 素材

`assets/blueberry-story-v1.png`: 内蔵image_genで生成した透過シート。元絵のpancakes-3/4/5.webpを絵柄・ポーズ参照に使用。生成プロンプト全文は `assets/PROMPT.txt`。PNGのalphaを保持し、元ファイルを上書きしていない。

## 検証と残る評価

`node --test tools/preview/pancakes/story.test.mjs`。章内の進行、早い章末、重複通知、小物台帳の保存則を確認。台帳テストは画像の物体数を自動検出するものではない。画像全6セルの4枚のパンケーキ・果物・ブルーベリーの位置は目視で照合する。

今回は6場面の短い話の動機・危機・解決を試す段階。長い読書での飽きに対する十分なバリエーション、楽しさ、元絵と同等の可愛さはユーザー評価が必要。単にコマ数を増やしたことで解決したとは扱わない。
