# パンケーキの小さな劇場

Refs #54。既存の6枚のストーリー画像とは別に、既存くま4ポーズとSVGの小道具で24の状態を演じる独立試作。

リポジトリ直下で `python3 -m http.server 8931` を起動して、`http://127.0.0.1:8931/tools/preview/pancakes/` を開く。既にサーバがある場合はそのまま使う。

- 「動きを見る」: 一操作で一コマ。「試写の設定」で任意のコマへ移動できる。
- 「本文の横で読む」: 公開本文「トロッコ」を読む。通常9ページ、細かい区切り60ページ。長編そのものではなく、長い章の進行を短い作品で模擬する。
- 「章を読み終える」: その時点で積んだ枚数だけを崩す。通常のめくりでは最後のコマで待つ。
- 読書モードは不規則な間隔で進行。早い連続操作は演出を抑制、280ms以内の二重入力は無視する。読書時間の判定はまだない。
- 通常の動きは900〜1100ms。常時ループなし。OSまたは設定の「動きを減らす」で静止画へ即時切り替え。
- 本文は演出に渡さない。保存・API通信・本番のθ制御との接続なし。UIは試写用で、拡張の読書画面を変更しない。

`story.js` は台本・進行、`scene.js` は既存画像とSVGの舞台、`preview.js` は本文と操作。画像は `extension/assets/bear/`、公開本文とページ分割は `../emaki/` を利用する。新たな画像生成は行っていない。

検証: `node --test tools/preview/pancakes/story.test.mjs`。進行・停留・重複入力・短い章での終了を確認する。試写の印象、読書の邪魔にならないか、長時間の飽きはユーザー評価待ち。本番統合時にθと実際の章境界を接続する。
